# Routine Tracker

毎日のルーティーンをチェックして、日次・週次・月次で達成状況を確認するシンプルなWebアプリです。
HTML / CSS / JavaScript だけで動くので、GitHub Pages にそのまま置けます。

## 機能

- **日次**：その日のルーティーンをタップしてチェック。達成率と連続達成日数を表示。前後の日にも移動して後からチェック可能
- **週次**：月〜日の表でチェック状況を一覧。ルーティーン別・日別の達成率
- **月次**：カレンダーで日ごとの達成度を色分け表示。ルーティーン別の月間達成率
- **設定**：ルーティーンの追加・名前変更・並び替え・削除、実施曜日の指定、バックアップの保存／読み込み

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成（例：`routine-tracker`）
2. `index.html` / `style.css` / `app.js` / `README.md` をアップロード（「Add file」→「Upload files」でドラッグ＆ドロップ可）
3. リポジトリの **Settings → Pages** を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2分後、`https://<ユーザー名>.github.io/routine-tracker/` で開けます

スマホではブラウザの「ホーム画面に追加」をしておくとアプリのように使えます。

## データの保存について

- 記録はブラウザの localStorage に保存されます（サーバーには送信されません）
- 端末・ブラウザごとに別々のデータになります。端末を移るときは「設定 → バックアップを保存／読み込む」を使ってください
- ブラウザの履歴・サイトデータを消去すると記録も消えるので、ときどきバックアップを推奨

## ルーティーンの初期値を変える

`app.js` の先頭にある `DEFAULT_ROUTINES` を書き換えると、初めて開いたとき（またはリセット時）のルーティーンが変わります。
すでに使い始めている場合は、画面の「設定」から編集してください。
